


Este proyecto consiste en una aplicación móvil desarrollada con Flutter y Dart que funciona como un portfolio personal. En ella muestro información sobre mí, mis gustos y aficiones, además de una sección dedicada al navegador Brave y un código QR.

La aplicación tiene una interfaz sencilla, con diferentes colores, imágenes y una barra de navegación inferior para cambiar entre las secciones disponibles.

 Funcionalidades
Cabecera personalizada: muestra el título «Este es mi portfolio».
Perfil personal: incluye una imagen de perfil y una breve descripción personal.
Sección de hobbies: presenta mis gustos y aficiones organizados en dos columnas:
Ver la puesta de sol.
 .Escuchar música.
 .Pasear.
 .Ir a la playa.
 .Coches.
 .Deportes.
 .Amanecer en la playa.
 .Cyberpunk.
 .Cine.
 .Mar.
 .Kebab.
 .Viajar.
Sección de Brave: muestra el logotipo del navegador, un mensaje personalizado y un código QR.
Navegación entre secciones: permite cambiar el contenido de la aplicación mediante una barra de navegación inferior.
Diseño personalizado: utiliza colores, contenedores, imágenes y diferentes estilos de texto.📱 Mi Portfolio Personal
